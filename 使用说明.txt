书书桌宠使用说明
================

1. 双击「启动桌宠.bat」即可运行。
   （需要系统已安装 Python 3.9+ 和 Pillow 库；一般执行
    pip install pillow  即可）

2. 启动后桌面右下角会出现一只透明背景的动图桌宠。

3. 操作：
   - 左键按住拖动：移动桌宠
   - 右键：弹出菜单
       · 切换动画：在 10 个 GIF 之间切换
       · 大小：小 / 中 / 大 / 调节大小（滑块，无极缩放，拖动实时预览）
       · 字体颜色：自定义余额和缓存文字的显示颜色（弹出系统取色器）
       · 立即刷新余额 / 余额详情 / 缓存命中率探测
       · 跟随 Codex（切换）：打开 Codex 时显示，关闭时隐藏
       · 置顶（切换）：保持窗口在最前
       · 退出：关闭桌宠
   - Ctrl + 滚轮：直接连续缩放桌宠大小

4. GIF 来源：
   - 优先读取 D:\文档\Angelina\GIF 下的全部 .gif（你的原目录）
   - 如果该目录不存在，会自动使用本文件夹下 gifs\ 里内置的 10 个动画
   - 想加新动画：把 GIF 放进 gifs\ 文件夹后重启即可

5. 提示：程序是透明窗口，图标会在任务栏显示；
   如需隐藏任务栏图标，可自行用 pyw 后缀或打包工具处理。
